How it works

Four steps. No opinions.

The whole story →
01 · PointA repository or a zip

Pick a commit, or drop a file. Read into a sandbox, never into storage.

02 · BootStarted cold, for real

Dependencies installed, project compiled, server up. If it does not boot, the report says where it stopped.

03 · Prove75 checks, deterministic

Structure, install, contract, behavior. Same input, same verdict. Every failure named with its evidence.

04 · ShowA badge and a public page

Tied to the commit. Goes grey on its own when unscanned commits land. One check posted to GitHub.

The public page

Honest by design

74 of 75 is a fail. With a name.

A verdict you cannot argue with has to be one you can inspect. Every failure is written in plain words with what the sandbox actually saw, and nothing is rounded up to "mostly".

Deterministic first. Same input, same verdict, every time. The core is open source, so anyone can read what a pass means. The layers are never listed, so there is no menu to game.
